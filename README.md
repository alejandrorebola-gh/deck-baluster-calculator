# Deck Baluster Spacing Calculator

A mobile-friendly static calculator that determines the fewest balusters needed to keep every clear gap at or below 4 inches. All spaces are equal, including the first and last gaps.

## Use locally

Serve this folder with any static web server, then open `index.html`. For example:

```sh
python3 -m http.server 8080
```

## Test

```sh
npm test
```

## GitHub Pages

The app uses relative asset paths and requires no build step. Publish the repository's root from the `main` branch in **Settings → Pages**.

> Field calculator only. Confirm the applicable building code and actual opening dimensions before installation.
